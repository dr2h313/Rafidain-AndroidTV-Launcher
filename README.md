## 🌟 نبذة عن المشروع (Overview)

تم بناء وتطوير **واجهة الرافدين (Rafidain TV Launcher)** ليكون البديل الإسلامي والرافديني الأمثل لواجهات التلفاز التجارية الممتلئة بالإعلانات والبطء وتتبع البيانات. 
صُمم النظام خصيصاً للمستخدم العراقي والعربي ليجمع بين **السرعة الخارقة**، و**الجمالية البصرية الراقية (زجاج شفاف Frosted Glass)**، و**الهوية الثقافية والروحية الأصيلة**.

---

## ✨ المميزات الرئيسية (Key Features)

### 1. خفة فائقة وبدون أي إعلانات (Zero Bloat & Zero Ads)
- إزالة كاملة لجميع الإعلانات والمقاطع المقترحة وإعلانات جوجل الإجبارية.
- إقلاع فوري في أقل من ثانيتين واستهلاك ضئيل للذاكرة والمعالج.

### 2. تكامل الشعائر ومواقيت الصلاة حسب فقه أهل البيت (ع)
- مواقيت الصلاة الدقيقة (الفجر، الشروق، الظهر، العصر، المغرب، العشاء) حسب أفق العراق والمنطقة (طريقة الشيعة الإمامية).
- ويدجت ذكي مباشر بجانب الساعة يعرض وقت الصلاة القادمة بنظام 12 ساعة مع صوت أذان عراقي أصيل.

### 3. ويدجت الطقس العراقي الحي (Live Weather Widget)
- قراءة لحظية لحالة الطقس ودرجة الحرارة وسرعة الرياح عبر محرك Open-Meteo بدون الحاجة لمفاتيح API.

### 4. نور العترة (دعاء وزيارة اليوم المبارك)
- بطاقة روحانية يومية تضم أدعية الأيام المأثورة عن أئمة أهل البيت (ع) وأحاديث نبوية شريفة.

### 5. شاشة توقف روحانية ذكية لحماية الشاشات (OLED Burn-in Protection)
- تعمل تلقائياً عند ترك التلفاز مع حركة انسيابية عائمة (Drifting) تمنع تطبيع واحتراق شاشات OLED.
- بطاقة ليلية فاخرة بنسبة تعتيم 88% لقراءة واضحة ومريحة للأدعية والزيارات.

### 6. ثيمات وخلفيات 4K مدمجة داخل التطبيق
باقة من الخلفيات السينمائية الفاخرة المدمجة بالكامل:
- 🏛️ مرقد أمير المؤمنين الإمام علي (ع) - النجف الأشرف
- 🕌 بين الحرمين الشريفين - كربلاء المقدسة
- 🦁 بوابة عشتار - حضارة بابل الخالدة
- ⭐ زقورة أور - حضارة سومر العريقة
- 🌴 شط العرب وبساتين البصرة الفيحاء
- 🌀 ملوية سامراء - حضارة الرافدين
- ⚫ وضع الخلفية السوداء النقية لشاشات OLED

## 🚀 التثبيت السريع بنقرة واحدة (Quick Installation)

### لمستخدمي Windows:
1. فعّل **تصحيح أخطاء الشبكة (Network ADB Debugging)** في شاشتك الذكية.
2. شغّل ملف التثبيت التلقائي:
   ```cmd
   setup_tv_iraq.bat
   ```
3. سيتصل السكرت بالشاشة ويثبت الواجهة والخلفيات تلقائياً خلال 30 ثانية.

### لمستخدمي Linux / macOS:
```bash
chmod +x setup_tv_iraq.sh
./setup_tv_iraq.sh
```

### التثبيت اليدوي المباشر:
يمكنك نقل ملف الـ APK الجاهز الموجود في مجلد `release/` وتثبيته مباشرة على أي شاشة أندرويد عبر فلاش ميموري (USB) أو تطبيق Send Files to TV.

## 🛠️ البناء من المصدر (Build from Source)

المشروع مبني بلغة Java الأصلية لأندرويد ومتوافق مع Android Studio و Gradle:

```bash
cd launcher
./gradlew assembleDebug
```

الملف الناتج سيكون في:
`launcher/app/build/outputs/apk/debug/`
